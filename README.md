# Radiant Insights Hub

"做一个智慧光伏平台，6个一级菜单，要求：

光伏相关科技风背景，光伏相关配色为主色调，带智慧光伏风格背景图

毛玻璃半透明卡片，带流光渐变边框和hover浮起效果

顶部固定导航栏，左侧3个图标菜单（图标+文字）+大标题居中+右侧3个图标菜单（图标+文字），导航栏也要有玻璃质感

每个页面内容布局要有明显差异，内容要非常丰富：统计数据卡片 + 多种echarts图表（折线、柱状、雷达、饼图混排）+ 数据表格 + 状态指示器

数据要有立体感和色彩冲击力，整体炫酷、现代、有科技感"
